# Broadband Access

Broadband Access Systems, Inc. was a Westborough, Massachusetts networking company founded in 1998 that built a next-generation Internet Protocol (IP) broadband access platform — a carrier-class cable-modem termination system (CMTS) that let cable operators and communications service providers deliver data, voice and video services over hybrid fiber-coax networks at scale.

ADC Telecommunications agreed on September 20, 2000 to acquire Broadband Access Systems for approximately $2.25 billion in ADC common stock; the acquisition closed on October 2, 2000. The company was absorbed into ADC's cable and broadband business, which ADC later divested. ADC itself was acquired by TE Connectivity in 2010.

Backed by: matrix-partners (alongside North Bridge Venture Partners, Norwest, Blueprint Ventures, Bowman Capital Management)

## Status

**Defunct since 2000.** The company shipped hardware platforms, not APIs, and operated no public developer program. It has had no independent web, documentation, or API surface since the ADC acquisition. This repository is retained as a historical venture-portfolio record only — no API artifacts exist or will be generated.
